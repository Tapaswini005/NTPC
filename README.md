# 🔧 Automated Predictive Maintenance System

## 📌 Project Overview

The Automated Predictive Maintenance System is a Machine Learning-based web application developed using Python and Streamlit. The system allows users to upload a maintenance dataset, train a machine learning model automatically, and predict whether a machine requires maintenance.

This project is designed to help industries identify potential equipment failures before they occur, reducing downtime and improving operational efficiency.

---

## 🎯 Objectives

- Predict machine maintenance requirements using Machine Learning.
- Allow users to upload their own datasets.
- Automatically train a predictive model.
- Provide an easy-to-use web interface.
- Improve decision-making through predictive analytics.

---

## 🚀 Features

- Upload CSV datasets.
- Preview uploaded data.
- Select target column dynamically.
- Automatic data preprocessing.
- Random Forest Machine Learning model.
- Model accuracy evaluation.
- Real-time maintenance prediction.
- User-friendly Streamlit interface.
